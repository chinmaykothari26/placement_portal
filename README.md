# Placement Portal

## Project Description

Placement Portal is a simple Python command-line application designed to manage basic student placement information.

The project uses beginner-level Python concepts such as variables, input/output, conditional statements, loops, lists, and functions.

## Features

* Enter student details
* Display student information
* Generate and display student ID
* Enter placement-related information
* View placement information
* Command-line based interface
* No GUI setup required

## Technologies Used

* Python 3

## Requirements

The following software is required:

* Python 3.x
* Command Prompt / Terminal

No external Python libraries are required.

## Installation

### Step 1: Install Python

Install Python 3 on your computer.

Verify the installation by opening Command Prompt or Terminal and running:

```bash
python --version
```

If your system uses `py`, run:

```bash
py --version
```

## Download the Project

Clone the GitHub repository using:

```bash
git clone https://github.com/YOUR-USERNAME/placement-portal.git
```

Replace `YOUR-USERNAME` with the actual GitHub username.

Move into the project folder:

```bash
cd placement-portal
```

## Dependencies

This project does not require any external Python packages.

No additional dependency installation is required.

## Configuration

No additional configuration, API keys, database setup, or environment variables are required.

## Running the Project

Run the following command:

```bash
python main.py
```

If `python` does not work, use:

```bash
py main.py
```

The program will start directly in the terminal.

## Usage

1. Run the program using the command shown above.
2. Follow the instructions displayed in the terminal.
3. Enter the requested student information.
4. Enter the required placement information.
5. View the information displayed by the program.
6. Follow the menu/options provided by the application.
