# Student Placement Portal - Project Statement

## 1. Problem Statement

The placement process in colleges involves managing student information, company details, eligibility criteria, job applications, and application status. Managing these activities manually can make the process difficult to organize and track.

The Student Placement Portal is developed to provide a simple command-line based system for managing basic placement activities. It allows students and placement-related users to register student details, add company information, check eligibility, apply for jobs, and view application status.

## 2. Scope of the Project

The scope of this project is to provide a basic placement management system using Python.

The project covers:

- Student registration
- Company information management
- Viewing available companies
- Checking student eligibility for companies
- Applying for available jobs
- Checking application status
- Storing placement-related information using a local database

The project is designed as a beginner-level command-line application and can be extended in the future with features such as a graphical user interface, login system, notifications, and advanced placement reports.

## 3. Target Users

The main target users of the project are:

### Students
Students can register themselves, check their eligibility for available companies, apply for jobs, and view their application status.

### Placement Coordinators
Placement coordinators can add company information and manage basic placement-related data.

### College Placement Cell
The placement cell can use the system to organize student and company information and manage the basic placement process.

## 4. High-Level Features

The main features of the Student Placement Portal are:

1. **Register Student**  
   Allows students to enter and store their basic information.

2. **Add Company**  
   Allows company and job-related information to be added to the system.

3. **View Companies**  
   Displays the companies available in the placement system.

4. **Check Eligibility**  
   Allows eligibility of a student for a company to be checked based on the available criteria.

5. **Apply for Job**  
   Allows eligible students to apply for available job opportunities.

6. **View Application Status**  
   Allows students to check the status of their job applications.

7. **Command-Line Interface**  
   The complete application can be executed directly from a terminal using Python.

8. **Local Data Storage**  
   Placement-related data is stored using a local database.
